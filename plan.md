# План автоматизации тестирования сервиса "Путешествие дня"

## 1. Введение

**Проект:** Веб-сервис "Путешествие дня"  
**Тестируемый функционал:**
- Обычная оплата тура по дебетовой карте
- Выдача кредита по данным банковской карты

**Цель автоматизации:** Обеспечить стабильную регрессионную проверку критического функционала оплаты/кредитования при каждом изменении кода.

## 4. Риски при автоматизации

### 4.1 Технические риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|------------|
| Нестабильная работа gate-simulator (Node.js) | Средняя | Высокое | Healthcheck в compose, retry в тестах |
| Нарушение порядка запуска контейнеров | Средняя | Среднее | `depends_on` + wait-for-it скрипты |
| Различия MySQL и PostgreSQL | Низкая | Высокое | Абстракция через фабрику БД |
| Flaky-тесты из-за сетевых задержек | Средняя | Среднее | WebDriverWait, timeouts |
| Баги в самом эмуляторе | Низкая | Критическое | Отдельные API-тесты на gate-simulator |
| Проблемы с ChromeDriver в CI | Средняя | Среднее | Контейнер с Chrome или Selenoid |

### 4.2 Риски поддержки

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|------------|
| Изменение CSS-селекторов в вёрстке | Высокая | Среднее | Page Object Model + data-атрибуты |
| Изменение текстов ошибок | Средняя | Низкое | Паттерн-матчинг, не хардкод |
| Обновление версий библиотек | Низкая | Низкое | Фиксация версий в requirements.txt |

### 4.3 Организационные риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|------------|
| Отсутствие документации по БД | Средняя | Среднее | Reverse engineering через `DESCRIBE` |
| Смена URL сервисов | Низкая | Высокое | Всё в `.env`, без хардкода |
| Нехватка времени на отладку | Средняя | Среднее | Приоритизация P0-сценариев |
