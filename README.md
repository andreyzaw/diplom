# Дипломный проект по профессии «Тестировщик»

Дипломный проект — автоматизация тестирования комплексного сервиса, взаимодействующего с СУБД и API платежной системы.

## Развертывание приложения

1. Склонировать репозиторий с проектом: **git clone**
2. Выполнить команду: **docker-compose up -d**

Проверить что приложение запустилось:

После того как все три контейнера поднимутся (Java-приложение может запускаться чуть дольше), откройте браузер и проверьте:

Веб-интерфейс: http://localhost:8080

Логи эмулятора: **docker logs gate-simulator -f**

Логи приложения: **docker logs aqa-shop-app -f**

Если всё настроено верно, приложение подключится к БД и эмулятору, и вы сможете тестировать платежи.
